Your agent can read the same corpus, refine the current question, and update this view through a local companion.

  2. Start the local companion using the agent setup instructions.

The same-origin local page is the reliable bridge. A public HTTPS page may be blocked from accessing a loopback HTTP companion by browser network policy.
