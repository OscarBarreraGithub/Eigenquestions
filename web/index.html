About this explorerSource & reproducibility ↗

Explore with your agent

An agent with browser execution can inspect this page, compute an orientation without changing your path, or apply a complete source-linked view. It can also save that view as a link. Graph suggestions supplement independent research.

Agent instructions and supported actions

Use a local companion
  1. Get the repository and install its portable navigation skill.
  2. Start the companion using the setup instructions.
  3. Open its local browser link. Agent actions update that page automatically.

The companion’s local page is the reliable bridge. A public HTTPS page may be blocked from accessing a loopback HTTP companion by browser network policy.
