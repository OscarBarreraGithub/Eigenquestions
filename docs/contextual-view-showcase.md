# A scientific view that travels with the conversation

Request: Q-003 / Q-004. Showcase notes, not a claim that hosted storage is live.

**The idea:** your agent does the thinking and computation; Eigenquestions makes
the result easy to inspect, continue and share.

Ask about Kaluza–Klein towers, then ask whether they could be dark matter. The
useful organization may change: papers, methods and connections about the Dark
Dimension become relevant. The agent does not merely zoom a fixed topic tree.
It records a new view of the literature: the chosen sources, meaningful groups,
their names, the evidence connecting them, and sensible next directions.

That complete view travels as a file. When hosted storage is enabled, saving it
returns a short link; another browser can display the same scientific decisions
without running the agent again. A manual file drop provides the same rendering
path. The browser stays responsive while loading or computing a new view.

**What makes the mechanism useful**

- A small link can refer to a rich result without squeezing the science into a URL.
- The result preserves the agent's actual labels and grouping, including overlap.
- The website needs no model service: computation stays with the agent or browser.
- Sources and construction details remain inspectable; visual proximity is not
  presented as a proof of a physical connection.
- A view can be useful to an agent even when its human never opens the website.
  Graph orientation supplements the agent's independent research and paper checks.

**A good demonstration:** show the starting question, the contextual pivot, the
resulting five directions and a source supporting one connection. Export it, open
it in a fresh browser, and compare the labels and evidence. Explain separately
which actions can continue from this object: displaying a saved result does not
guarantee that every outside builder's algorithm can be rerun locally.
