# One scientific question, shared by browser and agent

Q-025 development checkpoint, 2026-11-17. The integrated mechanism is tested;
the complete accepted scientific release is still being assembled.

A researcher should be able to reach the same scoped question through different
topics or a justified paraphrase, inspect its sources, and continue from the same
record. Prepared destinations carry stable IDs inside an immutable atlas version.
Their compact links need no upload. An agent interprets the conversation and checks
the scope; browser search only matches titles and aliases.

A question's premises matter. Production, a threshold-decay calculation and
conditional cosmological signatures can be connected without becoming one
question. Directions follow the scientific structure—usually about 1–15 useful
choices—not a fixed branching factor. The broad physics entrance is a separately
identified classification vocabulary, with explicit portals into the detailed
source collection.

## How the team constructs and steers the atlas

1. Numerical work proposes neighborhoods from the existing graph and embeddings.
   Source rows, hashes and alternative constructions remain inspectable.
2. A scientific agent reads the supplied descriptions and selected primary
   excerpts, records scope and contributions, and states what remains unread.
3. An independent challenge checks distinctions, boundary cases, source support
   and proposed identities. Agreement alone does not turn an extraction into a
   theorem; actual source and reading qualifications remain attached.
4. Review and steering resolve disagreements, split or broaden scopes, preserve
   legitimate overlaps, and withhold unsupported equivalences. Code checks exact
   provenance, membership conservation and the admitted decisions before export.
5. The same recorded IDs, typed connections and source context drive browser,
   static pages and the agent protocol. Integration tests check path/replay,
   source paging, notes and the browser's acknowledgement of agent updates.

A useful failure is the numerical KK/GZK neighborhood: a spectral-cutoff question
and KK-decay cosmology can be nearby while asking about different systems and
observables. The source challenge calls for separating their scientific questions
while retaining justified framework connections. This is a steering example, not
permission to declare the unreviewed numerical cluster a canonical question.
[Source-qualified examples and construction](../construction.html) describe that
case and five other ways assumptions change interpretation. The
[single notebook](../Lab%20Notebook.md) records the experiments and decisions.

## What travels between people and tools

A prepared link selects an exact versioned destination. Back, replay and another
entry path preserve its identity; a changed defining premise may require another
record. Scope, methods, assumptions, source contributions and reading limits stay
inspectable. Contributions such as comparison or method remain distinct from
membership, equivalence and established applicability.

A full authored capsule remains the option for new labels, overlapping groups or
context not yet represented by an installed destination. It travels as JSON/gzip
and can use a saved link when hosted storage is available. Local work notes attach
to destination IDs and export separately; ordinary destination links and view
exports do not publish them. Graph orientation supplements independent research.

**Publication and storage:** the final accepted atlas, its counts, public connection
results and current hosted-storage status must be recorded at release. Prepared
links do not depend on upload storage. If saving an authored view fails, retain its
file and report that no durable saved link was made.
