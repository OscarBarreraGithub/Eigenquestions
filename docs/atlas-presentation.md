# Physics scope and record history

A destination's scientific definition is preserved exactly. A separate,
versioned `displayEditorial` annotation can put a workflow or reading note in its
proper section instead of presenting it as a physical assumption. This does not
admit a new scope, repair a scientific result or change question identity.

For example, “numerical membership is retrieval provenance” describes how the
atlas was organized. “Approximately zero numerical diagnostics do not prove
exact zeros” is a scientific qualification and stays with the physics. Keyword
filtering cannot reliably distinguish them.

Annotations name the original artifact and SHA-256, the exact destination and
field paths, and the unchanged `scopeContentSha256`. Each moved note must match
the original text exactly. A short display summary or reading-limit copyedit
also retains the complete original wording and explains the display decision.
A changed origin or text is an error, not permission to hide the new text.

The browser and plain static pages use the same projection. Physical assumptions,
regimes and conventions remain under scope; historical workflow notes stay in a
collapsed “Reading and record history” section. Reading counts and limitations
are readable prose, with the complete structured reading record available in a
secondary disclosure. The agent receives the original record plus its explicit
annotation and must distinguish both from the current scientific status.

The annotation is presentation metadata. It does not alter source allocations,
contributions, identity aliases, relations, current admission status or the
scientific content hash. A lazy catalog may carry the annotated display synopsis
for lookup and next choices; the complete original definition remains in its
checksummed destination detail. A new package version pins any display change.

An unresolved source facet may carry an explicit `sourceHomeNotice` alongside
`sourceHomeStatus: "unresolved"` and its unchanged `sourceHomeReason`. The browser
and static page show that notice and retain the full reason in “Placement context”.
This distinguishes an unestablished topic placement from missing source context;
the renderer never infers the distinction from keywords. Existing facets without
the optional field keep their recorded context-specific display fallback. The
notice does not create a home, source mass or canonical equivalence.
