This is a missing admission decision, not a reason to reread every source or reconstruct the numerical method.

The second approach is scientifically viable if the actual source geometry is visible and linked to canonical question anchors, with anchor position explicitly meaning an evidence location, not cluster mass or equivalence. A disconnected source footprint should remain a visible multiple footprint or a relational destination, rather than acquire a misleading midpoint. It is a useful fallback for questions without admitted homes. As the primary release design, it introduces more presentation work and makes the requested readable question organization less direct. The first approach is the smaller coherent continuation of the existing assembler and stated goal.

The minimal bridge is:

1. **Reconcile scopes first.** Reuse an exact canonical ID only through admitted same-scoped-question decisions. Common targets, specializations and changed premises remain distinct. Remapping an already admitted home through unchanged admitted equivalence is deterministic; remapping a contribution to a home is not.
2. **Admit exact organizational homes from existing evidence.** Agreed `addresses`, `instantiates` and `specializes` roles nominate candidates. The coordinator can approve a candidate when the exact admitted scope, source target, conditions and paired reading support that organizational inclusion. Bind the exact canonical scope and source/review evidence in a separate placement receipt. Call it coordinator adjudication from independently read evidence, not independently agreed placement. The current assembler's old accepted-placement predicate requires `challengerAgreement: independently_agreed`; the bridge must use an explicit honest adjudication path rather than filling that field inaccurately. This is a narrow contract adjustment, not a new research framework.
3. **Keep uncertain coverage meaningful.** Use a separately admitted broader scientific home when a fine target is unresolved. An existing reviewed r scope can survive if it remains scientifically useful after reconciliation; its old batch ID or coverage alone is not a reason to retain it. Retire redundant r records to provenance. A boundary, comparison or method contribution never supplies home mass solely because of its role. A source can directly study a limitation or negative result, so inclusion should concern its actual target and study conditions, not assume the paper proves the destination's answer.
4. **Normalize once after final identity mapping.** Deduplicate repeated review appearances and collapsed canonical IDs before allocating each immutable Q across its explicitly approved homes. Equal weights are a transparent organizational convention; use unequal weights only with an explicit policy/evidence basis. Preserve one total unit of allocation per Q and the existing paper-balanced mass. Keep exact source access and unresolved fine identity independent of these weights. No contribution-only question needs invented mass.
5. **Use the final scientific graph for routes and views.** Admitted containment gives true multi-parent subset structure; comparison, method and application routes support cross-field traversal without creating containment or extra mass. Final direct-home destinations, including genuinely useful broad questions, can supply H columns. Ancestor membership is a derived union. If a broad fallback is also an ancestor of fine bases, distinguish its directly allocated residual mass from its full descendant-inclusive displayed scope; never count the latter again as a second allocation. Show about 1–15 useful directions per view while keeping all admitted connections accessible. This is a presentation choice, not a cap on scientific resolution.

New model review is warranted only where the decision is substantively missing: an altered canonical target or premise, incompatible source conditions, conflicting role/placement judgments, an unsupported new broad fallback, a compound target whose homes cannot be justified from existing readings, or a disputed public relation. Use a bounded proposal/challenge or source-based coordinator adjudication for that case. A factor annotation revision, an unresolved source-equivalence state, or an unmatched candidate label alone does not erase independently supported target evidence. Conversely, a convenient role label cannot resolve an actual premise conflict. The current paired reviews are evidence for these decisions, not a license to invent them.

Before scaling, finish the small KK rehearsal through actual H and geometry: keep production, threshold dynamics and conditional cosmology distinct; enter from another branch and return through a different route; verify canonical IDs, exact sources, noncontainment relations, overlap conservation and zero-mass question access. Include at least one no-core-contribution/compound case and one ordinary or pre-Swampland source with a meaningful broad home. Inspect displayed centroid distortion and disconnected footprints, not just hidden numerical atom quality. Then scale the same explicit bridge. Optional human polish can refine labels, menus and inspectable corrections; it should neither become a required manual ontology nor silently change scientific membership.
