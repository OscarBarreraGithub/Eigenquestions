Destination relations are directed navigation assertions with exact scope and evidence. They are not source-claim implications. These meanings were checked against the existing assembler before admitting the KK rehearsal.

| Type | Source → target meaning |
|---|---|
| narrower | Broader question → narrower question. Target scope is contained in source scope. This preserves the existing containment DAG convention. |
| premise_check | Conditional question → a premise question to investigate before transferring the conditional conclusion. |
| application_of | Applied question → underlying method or mechanism question. |
| method_for | Method question → question to which that method has scoped applicability. |
| comparison | Explicit comparison route; no containment, implication or equivalence. Reverse arcs are separate reviewed navigation records. |
| related_question | Qualified scientific route whose relationship is explained in the rationale; no stronger relation is implied. |

The initial-production question explicitly excludes later viability. Its route to threshold dynamics is therefore comparison, not a premise check. Forward routes to the flat-model and linear-cosmology applications use related_question with qualified labels. The reverse cosmology-to-rate and cosmology-to-initial-population routes are premise_check. Native proposed types remain in provenance, including the reviewers' reversed threshold/linear premise-check directions. No automatic relabeling rule is applied to other parents or leaves.
