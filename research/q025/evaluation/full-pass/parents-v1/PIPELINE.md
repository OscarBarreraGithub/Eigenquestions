# Parent synthesis from reviewed children

All55 parent regions have fixed source-contrast packets and110 proposal/challenge
templates. Their2–7 original children are provenance, not forced final parentage.
`parent_pipeline.py` combines actual bounded source rows with separately attributed
child definitions, question candidates, coverage counts and unresolved issues.
It never manufactures a source unit for a child region or claims that a parent
reviewer reread all descendant descriptions.

`build_child_artifact.py` consumes an exact completed challenge and its input,
checks every eligible original member and every sealed exclusion, and preserves
scope agreement separately from new challenger proposals. Existing child
questions receive reusable references in the parent packet; the reviewer should
link to them rather than author route-dependent duplicates. The source-only
compact output schema remains the same. Child scope assessments and explicit
narrowing/method/application/comparison links determine proposed parentage.

A parent proposal can start once all direct-child artifacts are frozen. Its
independent challenge starts after its own output validates. The resulting
artifact recursively feeds higher parents. No ancestor waits for unrelated leaves.
A failed child remains pending and visible in the dependency ledger; it is never
omitted from the claimed corpus coverage.

Parent support does not automatically accept a rewritten child scope. Fine
question equivalence, compound-source splits and direct placements remain
separate decisions. Parent sources are central/boundary contrasts, with complete
membership IDs and nonreserved description coverage pinned externally.

Three focused tests currently verify genuine contrast rows versus descendant
coverage, explicit child assessment, and independent parent-stage inputs.
Templates and local compilation make no native calls. The parent dispatcher will
use the already tested production runner mechanics once the first exact child
artifacts are available; root coordinates its concurrency with the leaf campaign.
