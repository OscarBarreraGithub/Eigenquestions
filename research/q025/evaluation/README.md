Local `.local.json` source excerpts/reservations and `native-review/native-local/`
are ignored and must not be copied into public site assets. Public-facing records
should use bounded summaries, primary source links and exact evidence references.

The evidence audit does not equate text affinities, literal mentions, source-local
assertions, organizational membership and independently reviewed cross-paper
relations. Each retains its own status and direction. A record/format pass is not
scientific truth, a complete-paper reproduction or an acceptance of all members.
