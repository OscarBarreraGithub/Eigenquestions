# Post-selection holdout protocol

The twelve visible journeys and eight ordinary probes are development/challenge
material. Do not call them blind successes after builders have inspected them.
`holdout-commitment.json` pins 24 unused navigation paper witnesses across eight
strata. Their source content has not been semantically inspected in this evaluation;
code has used their IDs only to exclude them from development/native samples.

Before opening the reservation, pin the chosen candidate definition/membership
hashes, canonical question cards, adapter version and release candidate catalog.
Do not tune while scoring. A failed case stays failed for that candidate; a repair
gets a new version and a separately labeled rerun.

For each reserved source, the evaluator reads actual primary excerpts and records
its target, material assumptions/regime, methods, relevant source IDs and reading
limits. It writes two natural independent formulations without paper title/ID or
copied card wording, plus one contrast changing a scientific target or hypothesis.
If a selected source is too poorly extracted, ambiguous or outside intended
coverage, retain it with that explicit status; do not silently substitute an easier
paper. The reservation is stratified diagnostic material, not a representative
random accuracy benchmark.

The evaluator independently inspects the frozen catalog and records the best
supported accepted destination, or a genuine scope/coverage gap, before seeing the
routing agent's output. Prior cluster assignment is never the answer key. If two
accepted cards cover the same defining question with incompatible IDs, record an
identity defect in the catalog rather than choose whichever the agent selected.
A broad related card can be useful orientation but is not a correct fine-grained
answer unless the unresolved specificity is visible.

A fresh routing agent receives the prose and the same public agent/browser
interface a researcher would have. It may read card definitions, evidence and
related directions; it must not see the expected ID, source membership or earlier
reviewer verdict. Capture its actual requested state/URL, resolved destination,
explicit perspective, constraints, selected evidence, reachable connections and
any declared gap. For at least eight cases use both an independent direct entry and
an alternative plausible route. Include extra dimensions ↔ cosmology and at least
three ordinary fields.

Check separately:

- **Identity:** Equivalent accepted formulations and alternate routes converge on
  one question ID, not merely a shared paper or region. A material contrast stays
  distinct or receives an honest gap. A presentation-only lens preserves identity.
- **Scope and science:** The returned card answers the actual target; assumptions,
  conventions and regimes survive. Source-attributed disputes and withheld outcomes
  are correctly represented. No affinity or source mention becomes an implication.
- **Readability:** A reader can explain what is asked, how it is studied, why each
  next direction is useful, and what it excludes. At least two moves add scientific
  specificity. A menu of synonymous labels over the same evidence fails this test.
- **Connections:** The same question/perspective exposes the same shared adjacency
  from both routes, with all recorded connections reachable beyond the 1–15
  foregrounded choices. Browsing backward preserves scientific arrow direction.
- **Protocol:** Click, agent selection and exact ID import reproduce state; reload,
  Back and opening the shared address restore it. Preserve original prose outside
  identity; renaming a label cannot change a target.

Report case-level evidence and disagreements. Distinguish correct specific matches,
correct explicit gaps, useful broad orientation, wrong scope, duplicate identity,
missing scientific content and interface failure. Do not count a correct gap as
covered science. Any unresolved source interpretation remains uncertain. Structural
validation, numerical stability, semantic routing and browser behavior have separate
results and denominators.
