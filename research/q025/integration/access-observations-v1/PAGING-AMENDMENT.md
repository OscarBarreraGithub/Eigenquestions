# Paging clarification

The Wave L README's “all incident connections remain paged” refers to the `navigator.connections` API. The browser's closed all-connections disclosure currently receives and renders the complete `atlas.connections` array; it does not page that disclosure. The default scientific choices remain bounded. The static page lists all incident links.

The forthcoming partial-candidate browser check will measure the largest actual incident-link destination and interaction latency. Browser lazy paging will be considered only if that measurement warrants it, preserving access to every link. This clarification does not change frozen Wave L code or evidence.
