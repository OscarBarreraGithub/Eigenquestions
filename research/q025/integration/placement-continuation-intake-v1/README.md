# Incremental completed placement pairs

Run `python3 research/q025/integration/placement-continuation-intake-v1/summarize.py` to write a new timestamped, read-only intake. It includes only complete challenge/proposal pairs from the original continuation, unstarted successor, missing-tail successor and explicit validator-timeout successor. The last uses its pinned, deterministically adopted proposal and independent challenge; the original timeout remains failed. Internal dependencies and explicit external proposal paths are verified; duplicate completed lineages for one family fail instead of being silently selected.

Each stage binds its validated reply, normalization, source packet, receipt and sidecar. Selected existing destinations retain the exact supplied scope hash. New definitions point to their exact normalized reply and require a global current-inventory lookup before scientific admission. All full explanations and coverage spans remain in those immutable inputs; the compact intake does not rewrite them.

Geometry owns the placement compiler. Evaluation and root handle scientific scope exceptions and admissions. These exports make no placement, identity or novelty decision and do not dispatch models.
