The atlas starts from source-linked physical questions, methods and other extracted scientific records. Several existing embedding views propose nearby questions; their similarity helps locate material but does not establish a physical relation. Reviewed question scopes and explicit source-home decisions determine the scientific destinations. A source can have several homes when its targets require overlap, with allocation weights summing to one. Original numerical review batches remain provenance, not automatically public branches.

The overview is computed **after** those decisions. Let \(H_{ir}\) be question \(i\)'s admitted allocation to scientific destination \(r\). Each paper receives equal total question mass, divided among its extracted questions. A reversible, source-balanced flow \(F\) is constructed from the pinned multiview affinities; the coarse flow is \(C=H^{\mathsf T}FH\). Diffusion coordinates summarize this flow in two dimensions. Displayed scope positions are source-balanced membership centroids, with measured distortion; a broad scope's descendant-inclusive membership is not fed back into \(H\) as extra mass. Spacing between disconnected components has no metric meaning.

Typed scientific and navigation links remain separate from chart affinity. Methods, comparisons, boundary examples and source assumptions retain their stated scope; they do not become source-home mass or an assertion that a method applies merely because they are nearby. Contribution-only questions remain accessible through their evidence and admitted routes without fabricated coordinates. The same stable destination can be reached from several scientific directions in both browser and agent navigation. Optional native query projection is a separate exploration mode, rather than the construction rule for this prepared atlas.

The broad physics entrance uses the pinned APS PhySH classification, a vocabulary map in a separate coordinate space. It is not an empirical all-physics paper embedding. Detailed chart coverage, source counts, reading limits and projection diagnostics belong to each versioned package.

Implementation note for the existing construction/showcase section: the five-question rehearsal exercises this pipeline, while complete scientific admission and allocation are still in progress. Do not present a partial rehearsal as the complete atlas, or describe the prepared atlas as the earlier five-direction PCA explorer. The pinned retrieval operator currently mixes MiniLM question affinity (0.5), Qwen question affinity (0.3) and same-paper method-context affinity (0.2). The last component is contextual retrieval, not an independently validated scientific edge. For off-diagonal symmetric affinity \(W_{ij}\), source mass \(m_i\), and degree \(d_i\), the implementation uses \(F_{ij}=W_{ij}\min(m_i/d_i,m_j/d_j)\), with residual self-flow chosen so each row sums to \(m_i\). A full release uses global question counts per paper; a partial rehearsal explicitly restricts and renormalizes its cohort.
